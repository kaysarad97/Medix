# MedIx / Medix — описание проекта

## Что это
Кроссплатформенный агрегатор в сфере здравоохранения для Казахстана, объединяющий:
1. **Телемедицину** — видео/аудио консультации с врачами, встроенный чат, оплата.
2. **Лабораторный чат-бот** — OCR-распознавание направлений от врача, сравнение цен на анализы между партнёрскими лабораториями («Олимп», «Интер» и др.), авто-запись.
3. **Подписочную модель** (Free / Silver / Gold) с приоритетным обслуживанием для Gold-пользователей (Buffer Strategy — 20% слотов врача резервируется под Priority, Smart Waitlist, Express-чат).
4. **Семейный доступ** — до 3–5 профилей на Gold-подписке (дети, пожилые родители).

Полное ТЗ (v1.0 MVP, от 27.05.2026) лежит в проекте — там же секции про compliance/дисклеймеры (AI-бот не заменяет врача, кнопка SOS/103, ограничение ответственности за качество OCR).

## Статус на данный момент
- **Дизайн:** обновляется. Старый Figma-файл (`App Prototyping`) больше не актуален — не использовать его как референс. Новые макеты — изображения, разложенные локально в `medix-app/design`. При работе над UI ориентируемся на эти файлы.
- **Backend:** в разработке параллельно (Python/FastAPI), пока не готов — фронтенд идёт по контракту API/моками.
- **Frontend:** старт с нуля на Flutter, архитектура feature-first + Riverpod (см. ниже).

## Технический стек
| Слой | Технология |
|---|---|
| Мобильное приложение | Flutter (iOS/Android) |
| Админ-панель | React/Vue |
| Backend | Python (FastAPI) |
| БД | PostgreSQL |
| OCR | Google Vision API / Tesseract |
| AI-чат/агенты | OpenRouter (LLM) |

## Архитектура Flutter-приложения
Feature-first структура, state management — Riverpod:
```
lib/
├── core/        # network, theme (design tokens), router, общие виджеты
├── features/    # auth, telemedicine, lab_chatbot, subscriptions, profile, family_access
└── shared/      # модели и сервисы, общие между фичами
```

## Важные ограничения продукта (из ТЗ)
- Бот не ставит диагнозы — только информационно-аналитическая поддержка; окончательное решение всегда за врачом.
- Приложение не для экстренных случаев — на главном экране обязательна кнопка/баннер «Вызвать 103».
- Точность OCR зависит от качества загруженного фото — компания не несёт ответственность за плохие исходники.
- Цены лабораторий — данные «как есть» из партнёрских API, могут устаревать.

## Как работаем
Весь код пишется через Claude Code / Claude Desktop. Design tokens и структура фич фиксируются в `core/`, чтобы каждая новая фича реализовывалась консистентно, без необходимости каждый раз пересказывать архитектуру.

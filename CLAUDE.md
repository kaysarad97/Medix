# MedIx — памятка для Claude Code

Агрегатор здравоохранения для Казахстана на Flutter. Что за продукт и какой
backend — в [PROJECT.md](PROJECT.md); что уже готово и какие решения приняты —
в [HANDOFF.md](HANDOFF.md). Ниже — только то, что нужно, чтобы не сломать
работу с первого шага.

## Язык

Код на английском, **всё остальное — на русском**: комментарии, doc-комментарии,
сообщения коммитов, тексты в UI, названия тестов. Это не стилевая прихоть —
заказчик читает и коммиты, и комментарии.

## Проверка перед сдачей работы

Три команды, всегда в этом порядке:

```bash
dart format --output=none --set-exit-if-changed . && flutter analyze --fatal-infos && flutter test --exclude-tags golden
```

`--fatal-infos` обязателен: CI валится на info-подсказках, не только на
ошибках. Ожидаемый результат последней команды — 141 тест зелёный.

## Эталоны (golden-тесты)

**Никогда не запускать `flutter test --update-goldens` на macOS.** Эталоны
сняты на Windows; растеризация текста и теней отличается, и локальная
пересъёмка молча перезаписывает рабочие эталоны отличающимися. Так уже
терялись 9 файлов — восстанавливали через `git checkout`.

- Локально на macOS golden-тесты просто не гоняем: `--exclude-tags golden`.
- Сверка идёт в CI, джоба «Сверка с макетами» на `windows-latest`.
- Пересъёмка — вручную запустить workflow CI с галкой `update_goldens`,
  затем скачать артефакт `goldens` и положить файлы в репозиторий:

```bash
gh workflow run ci.yml -f update_goldens=true
```

Тег объявлен в [dart_test.yaml](dart_test.yaml), файлы эталонов лежат рядом с
тестами в `goldens/`, папки `failures/` — в `.gitignore`.

## Архитектура

Feature-first, состояние на Riverpod 3, навигация на go_router.

```
lib/core/       — токены темы, общие виджеты, роутер, утилиты
lib/features/<фича>/{domain,data,presentation}
lib/shared/models/  — модели, которые нужны больше чем одной фиче
```

Новая фича повторяет эту структуру целиком; модель, понадобившаяся второй
фиче, переезжает в `shared/models/`, а не импортируется через `features/`.

Размеры, цвета, радиусы, тени и типографику брать из `lib/core/theme/*` —
магические числа в экранах допустимы только с комментарием-замером по макету.

## Иконки

Пять шагов, пропуск любого даёт пустое место на экране, которого не видно:

1. Дизайнер кладёт SVG в `icons/` под своим именем из Figma.
2. Скопировать в `assets/icons/` под ASCII-именем — кириллица и пробелы в пути
   ломают сборку Android (`non-ASCII characters` в Gradle).
3. Добавить значение в `enum MedixIcon` с комментарием, где иконка встречается.
4. Прописать путь в `MedixIcons._assets`.
5. Вычеркнуть из `MedixIcons.pending`, если иконка там была.

Всё это в [lib/core/widgets/icon_chip.dart](lib/core/widgets/icon_chip.dart).
`AppIcon` перекрашивает глиф, `BrandIcon` оставляет исходные цвета (нужен
логотипам платёжных систем), `AppIconChip` — глиф в круглой подложке.

## Тесты

Репозитории подменяются через `overrides` в `ProviderScope` фейками из
`test/helpers/`. Фейк обязан отдавать данные **синхронно**: `Future.delayed`
создаёт таймер вне `runAsync`, и виджет-тест падает на «timersPending». По той
же причине анимированные GIF в тестах отключаются флагом (`animatedWait: false`,
`animated: false`).

Шрифт грузится через `loadAppFonts` из `test/helpers/test_fonts.dart` — без
него текст рисуется прямоугольниками.

## Окружение

Flutter 3.41.8 — версия закреплена в CI (`FLUTTER_VERSION`) и должна совпадать
локально, иначе эталоны разъедутся. Работа идёт с двух машин (Windows рабочая,
macOS домашняя) через `main` в origin.
